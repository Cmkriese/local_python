# Project Layout

This project is a single-file web app. Keep project files in these locations:

- `index.html` at the top level for the app and GitHub Pages.
- `AGENTS.md`, `prompts.md`, and `spec.md` at the top level.
- `00_planning/` for plans, sketches, and design decisions.
- `01_data/` for source data and sample inputs.
- `02_validation/` for test cases and validation results.
- `03_output/` for screenshots and exported results.

Add a README to each numbered folder describing what belongs there. Keep the
detailed requirements in `spec.md`; do not implement app behavior until it is
defined there.

## Project Status

The starter files and folder structure are in place. Grocery Organizer
requirements and app behavior have not yet been defined.

## Working Rules

- Keep the specification synchronized with agreed requirements.
- After each request, update `prompts.md` with what was asked, changed, and
  whether it worked.
- After meaningful project or folder changes, add a dated entry to this
  file's change log.
- Keep the app in `index.html` unless the specification calls for additional
  source files.
